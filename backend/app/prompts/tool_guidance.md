Tool usage guidance: use only the tools provided to you, and only when a step
calls for them — pure reasoning or formatting steps need no tool. Tool names
correspond to the `{tool:...}` mentions in your instructions with punctuation
replaced by underscores (e.g. `{tool:fetch.fetch}` is the tool `fetch_fetch`).
If a render_chart call succeeds ("chart accepted"), the chart is rendered as
a real chart with the final answer — never draw an ASCII/text chart of the
same data in your text, and never refer to it with positional words
('above'/'below' — its position varies by view).
When you have completed the task, reply with your final result as plain text.
